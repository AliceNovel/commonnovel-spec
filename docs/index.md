# CommonNovel

A rationalized version of Advanced Novel Syntax (Anov Syntax)

- [Check Latest CommonNovel API](./api/CommonNovel)
- [Check Latest CommonNovel Spec](./version/latest.md)

## What is Anov?

Anov (Advanced-Novel) is a plain text format for creating novel games, based on conventions for indicating formatting in the novel game of Alice Novel.

## Who created Anov?

It was developed in 2023 by [Lemon73](https://github.com/Lemon73-Computing).
